## The argument

Software is a sequence of states transitioning according to patterns. Those patterns are learnable. Which means they don't need an explicit, hand-written implementation to look computed — they just need to be predicted well enough to satisfy the contract.

When you type `=A1+1` and see `11`, was the answer computed or predicted? If the contract is honored — same results, same invariants, same edge cases — what exactly is the meaningful difference?

Key points from the accompanying blog post:

- World models (Genie 3, LingBot-World) generate interactive environments with no game engine, no 3D models, no code — just `(history + action) → next frame`.
- The same principle applies to any software: a spreadsheet, a terminal, a file system. They are all learnable behaviors.
- We don't verify software by inspecting its mechanism. We treat it as a black box: feed input, assert output. If the tests pass, the contract is honored.
- Two boxes — one running a formula parser, one running a model that predicts what a formula parser would output — are indistinguishable if both satisfy the same contract.

## What this project demonstrates

Excellusion is a working spreadsheet powered entirely by an LLM, with **zero business logic in the code**. It comes in two modes that represent two levels of the same idea:

### Hybrid mode (A1:D8)

The UI exists as React code — the grid, the formula bar, the cell selection. But there is **no data layer**. No variables hold cell values. No formula parser evaluates expressions. When you edit a cell, the raw edit is sent to the LLM, which returns the full grid state as JSON. The React code simply renders whatever comes back.

The building has a front door, but nothing behind it.

### Full mode (A1:B4)

Even the UI is gone. The **entire spreadsheet** — every pixel, every cell border, every formula bar character — is generated by the LLM as pure static HTML. When you click, the browser takes a screenshot (with a red crosshair marking the click position), serializes the raw DOM event (including the real `data-cell` hit), and sends both to the LLM. The LLM looks at the image, interprets your action, and returns the next frame.

There is no building at all.

Full mode is disabled for ChatJimmy (Llama 3.1 8B) — too complex for that model.

## How to use it

### Prerequisites

- Node.js 22+ (managed via [mise](https://mise.jdx.dev/))
- An API key for the provider you pick (except ChatJimmy):
  - [Anthropic](https://console.anthropic.com/)
  - [OpenAI](https://platform.openai.com/)
  - [OpenRouter](https://openrouter.ai/)

### Setup

```bash
pnpm install
pnpm dev
```

Open http://localhost:3003 in your browser.

The default model is **Claude Haiku 4.5**. Paste a key in the top bar when the provider needs one. Keys are stored in `sessionStorage` (cleared when you close the tab) and never sent anywhere except the chosen provider. `.env` is for tests only — the website does not read it.

ChatJimmy needs no key; locally, Vite proxies `/chatjimmy-api` to https://chatjimmy.ai (their API has no CORS).

### Usage

- **Hybrid tab**: Click a cell, type a value or formula (`=A1+B1`, `=SUM(A1:A3)`), press Enter. The LLM computes the result. A1 is seeded with `1`; selection starts on B1. The **?** in the window title bar lists formulas to try.
- **Full tab**: Click or type anywhere. Watch the LLM regenerate the entire spreadsheet UI from a screenshot and the raw browser event.
- **Log pane**: Shows every request/response, cache stats, and the system prompt for the active model.

## Models

| Group | Models | Notes |
|---|---|---|
| Anthropic | Haiku 4.5 (default), Sonnet 5, Opus 5, Fable 5.1 | Messages API. Thinking off where allowed; Fable stays at effort `low`. |
| OpenAI | GPT-5.6 Luna, Terra, Sol | Responses API, `reasoning.effort: none`. |
| OpenRouter | Gemini 3.8 Flash, Grok 4.6, DeepSeek V4.1 Flash | Chat Completions. Effort `none` or `low` if thinking cannot be disabled. |
| ChatJimmy | Llama 3.1 8B | No key. Hybrid only. |

Dumber or smaller models often get formulas wrong. Prefer Haiku or Luna for Hybrid experiments.

## Tests

Live API tests (keys in `.env`, never committed):

```bash
pnpm test
```

`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, and `OPENROUTER_API_KEY` are used only here. ChatJimmy tests hit https://chatjimmy.ai with no key.

## Technical details

- **Prompt caching**: Anthropic `cache_control` (5m), OpenAI explicit breakpoints + 30m TTL, OpenRouter `cache_control`.
- **No app server**: Provider SDKs run in the browser (`dangerouslyAllowBrowser`). ChatJimmy is same-origin via the Vite proxy in dev.
- **Screenshot capture**: Full mode uses `html2canvas`, plants a DOM crosshair at the click, and sends `dataCell` from the iframe so the model does not have to guess pixels.
- **Framework**: React 19 + Vite + Tailwind CSS. Pure SPA — deployable to GitHub Pages.
